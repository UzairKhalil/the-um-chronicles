# The U&M Chronicles

A private two-person web app. Nothing here is of use to anyone else.

React + Vite · plain CSS · Vitest · Firebase Realtime Database · GitHub Pages.

```
npm install
npm run dev
npm test
npm run build
```

Editable content lives in `src/content/`. Engineering notes, deployment steps
and the traps worth knowing are in [CLAUDE.md](CLAUDE.md).
